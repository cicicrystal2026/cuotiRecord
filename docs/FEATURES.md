# 开发功能清单与优先级

版本基线：v0.1.0。编制日期：2026年10月7日。状态：P0已实现，本地自测通过；真实阿里云基础冒烟测试通过，复杂实际题待用户验收。

首版按本地单个孩子、高中数学设计。通过本机浏览器使用，数据在本地持久化；AI分析调用阿里云，题目图片和作答会按需发送至阿里云。本地运行不等于AI离线运行。

P0为首版必须完成并验证的闭环；P1为孩子真实使用后优先考虑的体验改进；P2为后续扩展。功能范围变化需同步版本PRD、技术文档和验收清单。

| F002 | 孩子与学期设置 | 一个昵称、年级、高中数学、教材、学期名称与日期；教材不确定允许暂存 | 创建学期后各页面范围一致 |
| F003 | 阿里云模型配置 | 服务端读取API Key、地域端点和模型ID；连接验证与失败提示 | 配置有效时真实调用；密钥不出现在前端或日志 |
| F004 | 图片录入 | JPG JPEG PNG，多图排序、删除，保留原件 | 清晰照片可录入，多张顺序正确 |
| F005 | PDF录入 | 支持普通可读PDF与扫描PDF逐页预览 | 页码与原文件一致，选题能定位到原页 |
| F006 | Word录入 | 支持DOCX，转换为可预览页面；.doc提示转换 | 文字、公式及图形保留可供核对，转换失败有提示 |
| F007 | 来源与学习日期 | 资料名称、实际学习日期、上传时间与学期归属；默认只记错题 | 回填上周日期后，历史按学习日期显示 |
| F008 | 识别与任务状态 | 图片或页面识别、候选拆题、状态展示；部分成功、失败、重试与恢复 | 失败不会丢原资料；刷新可恢复任务 |
| F009 | 核对与选题 | 原页与识别文本对照；修改题干、作答；手动补录一题；选择错题 | 至少选一道再分析，切换题目不丢内容 |
| F010 | 真实AI习题分析 | 使用阿里云模型分析标准解法、正确部分、错误位置、修正建议 | 展示真实调用结果，逐项可核对 |
| F011 | 高中数学考点匹配 | 首版覆盖函数、集合与常见基础内容；固定考点ID，允许人工修正 | 考点来自已有库；未覆盖的题明确待确认 |
| F012 | 逐题确认与分析版本 | 每题独立确认或待确认；保留原识别、用户修正与分析版本 | 确认一题不确认另一题；改题干使旧分析过期 |
| F013 | 缺少作答与不确定处理 | 无作答只提供考点和解法；条件不清、答案冲突标待核对 | 不输出确定个人错因，不进入薄弱推荐 |
| F014 | 学习历史与错题详情 | 按日期、资料查看；按考点与确认状态筛选；查看原题、分析、反思 | 能从历史回到原资料；筛选交集正确 |
| F015 | 考点列表与学习轨迹 | 已记录考点、相关题目、重复问题、历次重做；同题去重计数 | 计数可追溯，不把未记录考点标成不会 |
| F016 | 原题复习计划 | 选考点与题数；优先仍错、重复错误、未重做、到期验证；单题复习 | 待确认和无可靠答案的题被排除 |
| F017 | 独立重做与反馈 | 先隐藏答案，后核对；独立做对、提示后做对、仍错；暂停恢复 | 打开提示后不能记独立做对，刷新不重复保存 |
| F018 | 结果与状态更新 | 本次结果写入原题和考点；不同学习日且间隔24小时的两次独立正确记已验证 | 一次做对不标已验证；未完成不按错误计 |
| F019 | 修改删除与本地持久化 | 修改资料信息；删除单题或整份资料；存本地数据库和文件目录 | 删除影响范围明确；其他题保留；重启不丢记录 |
| F020 | 版本文档与验收交付 | 每版PRD、技术文档、逐页原型或截图、验收步骤、变更记录 | 文档功能ID与页面、实现和测试结果一致 |

## 建议本地验收顺序

1. 启动服务，建立一个学期，配置阿里云模型。
2. 分别用一张题目照片、一个扫描PDF、一个DOCX测试录入。
3. 修改识别内容，选两道题，逐题确认；再测试没有作答的资料。
4. 保存后看学习历史、原资料与考点统计；重启服务检查持久化。
5. 选一道已确认错题完成独立重做，再测试提示后做对和仍错。
6. 暂停并恢复，检查结果写入历史；测试不同学习日的验证条件。
7. 删除一道题和整份资料，检查影响范围；核对版本文档与验收记录。

真实阿里云调用需要有效API Key及可用模型权限。密钥应在本地配置，不能通过聊天消息传递；后续技术文档会给出具体配置位置。
