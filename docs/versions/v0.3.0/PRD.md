# v0.3.0 学科入口与分别记录

打开首页先选择语文、数学、英语、物理、化学、生物、政治、历史、地理。选择后进入该科概览，再录入已做题。资料固定归属于上传时学科，切换只改变查看范围，不迁移旧记录。英语保留AI分析和考点复习，其他科支持录入/读取/核对/做对错题标记/保存/历史，不冒用英语考点。页面截图和验证结果交付时补齐。

## 用户流程

打开应用 → 建档（首次） → 选择学科 → 本科概览 → 上传资料（固定学科） → 读取页面 → 核对题目与实际作答 → 标记做对/错题/未作答/待判定 → 保存 → 本科历史。英语另可AI分析、逐题确认、考点与原题复习。

## 业务规则

1. 学科ID固定：chinese/math/english/physics/chemistry/biology/politics/history/geography。首页先选科，卡片显示本科资料数和已保存题数；草稿仅计资料，不计已保存题。
2. 本科资料归属在上传时固定，切换学科只改变查询范围。资料原页识别出的subject是内容核对标签，与资料归属分开，不静默移动记录。
3. 历史按学习日期、作答记录保存；正确题也可保存，不能只记录错题。各科显示记录为做对/错题/未作答/待核对；英语分析状态仍显示待确认等证据状态。
4. 后端白名单验证学科，列表/历史/统计/考点/复习候选都按学科查。明确ID打开资料后按资料真实归属显示，不受上一学科影响。
5. 英语AI沿用v0.2.0规则；其他科暂不开放AI考点分析，按钮与服务端均阻止误用英语库。其他科历史不标成英语分析待确认，避免用户等待不可用功能。
6. 全局孩子、年级和学期沿用单档案，英语教材用于英语设置；当前不做每科课程表、授课班级、独立教材配置和跨学科考试预测。
7. 旧英语资料归english，原数学示例及math-*分析的资料归math；原件和题目不删除。混合学科资料首版应按科分别上传，不自动拆分迁移。
8. 浏览器当前会话记住选科学科，根首页始终选科；刷新已经进入的本科页面保留上下文。左侧选择学科可随时切换。进入资料深链按真实资料学科显示。

## 验收
