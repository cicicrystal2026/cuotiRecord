## 实现调整与理由

前期技术草案中的前端框架方案改为原生HTML/CSS/JS，服务端使用Python/FastAPI，减少本机安装与构建步骤；保留完整业务闭环。

Word预览采用OMML/嵌入图解析及浏览器内容重排，页面标注差异；复杂原版排版建议转PDF。数据库和原文件移到LOCALAPPDATA，避免WPS同步期间SQLite写入问题。单当前档案不实现日期隔离的多学期；后续新增独立semester迁移。
