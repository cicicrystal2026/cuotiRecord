## 真实AI验收建议

选择5—10道孩子实际做过的题，至少包括：普通计算、函数、手写作答、条件模糊、缺作答、超出当前考点范围、几何图形。每题核对题干与作答分离、参考解法、第一处错误、证据逐字定位、考点标签及不确定说明。若识别错误，先修正再分析；无法可靠判断保持待确认。

连接成功只证明接口可用，不证明题目分析正确。复杂图形必须补齐文字条件才用于纯文本复习；不可靠题不确认、不进入候选。
