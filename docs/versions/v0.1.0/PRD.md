# 知错 v0.1.0 产品需求文档

版本：0.1.0；日期：2026-10-07；状态：P0已实现，本地功能自测通过，待用户验收。真实阿里云基础冒烟测试通过，复杂题和孩子实际使用质量待用户验收。

## 1. 产品目标与边界

孩子把做过的高中数学题目和实际作答录入，获得可核对的解法及错误建议；以“学习时间—考点—原题—分析—历次重做”形成可追溯记录，考前选择有证据的不足进行原题复习。

首版是Windows本机网页，一个孩子、一个当前学期、数学。F001—F020为本版范围，见[功能清单](../../FEATURES.md)。不做账号、多学期切换、云同步、自动批改重做照片、变式题、复杂裁剪/拆并题、打印导出。现有原型为实现页面截图；示例资料均明显标注，截图不作为模型质量证据。

首批考点为基础库15项。没有记录不等于不会；记录了某题不等于学过该章节全部内容；统计表示本机档案覆盖，不推断全学期教学完成率。

## 2. 用户与主要流程

孩子：录入、核对、看分析、纸上重做、留结果。家长：协助配置模型与检查分析，不设独立权限。

```mermaid
flowchart LR
 A[建立档案] --> B[录入图片/PDF/DOCX]
 B --> C[生成预览]
 C --> D[AI识别或手动录入]
 D --> E[核对题干和实际作答]
 E --> F[AI分析或手动分析]
 F --> G{逐题确认}
 G -->|证据充分| H[保存已确认]
 G -->|缺作答/有疑问| I[保存待确认]
 H --> J[学习历史与考点轨迹]
 I --> J
 J --> K[选择可靠原题复习]
 K --> L[先作答再核对答案]
 L --> M[记录独立对/提示对/仍错]
 M --> J
```

## 3. 业务规则

1. 学习日期允许过去日期，不得晚于当天；上传时间另存。资料属于唯一当前档案，学期起止日期是档案信息，不作为隔离过滤。修改学期信息不会把历史数据分成新学期；创建和切换独立学期属于P1。
2. 一次上传最多20张图片，或一个PDF/DOCX；图片10MB/张、文档30MB，总页数20。JPG/JPEG/PNG，旧DOC提示转格式。保留原件，可下载。PDF页码保持原件；DOCX以重排后的预览页码定位，不承诺原Word页码一致。
3. 原页用于识别和核对；识别不直接确认。题干与作答分开，不能把参考答案当作孩子作答。跨页/模糊/依赖未补齐图形条件的题应人工补全或待确认。
4. 作答状态可选错、对、未答、暂不确定。默认错题，但由用户核对。选择开关控制保存，未选题保留在资料草稿。保存至少一道。
5. 每次题干、作答、缺失标记或作答状态的实质变化产生新版本，旧分析失效；题号、选择及反思修改不使分析失效。冲突返回提示，不覆盖他人窗口的新版本。已存在题目在浏览器暂存核对草稿；新建题必须点击保存。
6. AI先独立求解再比较实际作答。结构包括答案/解法、正确部分、问题、作答连续证据、检查动作、考点、错因、不确定说明。图文发送阿里云，AI非离线功能。
7. 固定考点ID最多3项，错因最多2项。考点范围外进入待确认。错因证据必须在实际作答中逐字定位；没有实际作答，只能暂存解法与考点建议，不确认个人错因、不入复习候选。
8. 各题独立确认。确认要求当前版本、可靠答案、至少一个库内考点、无未解决疑问；错题还需错误说明和真实证据。用户修正另存变更日志，原模型建议保留。手动分析和示例有来源标签。
9. 题目状态：待确认、需要巩固、本次独立做对、已验证；确认的正确题为已接触。当前版本才用于验证；一题关联多个考点时每个考点计一次，不因多次确认或重做重复计题。
10. 复习候选必须是保存的错题、当前已确认分析、作答完整且答案可靠。默认排除已验证题；错题详情仍允许单题重做。优先上次未独立正确、同错因在多题出现、未重做、需要再次验证；提示为证据规则，不预测考试分数。
11. 复习快照按题目版本固定。未核对前服务端不返回答案；提示只返回检查动作，查看提示会永久标记本次提示。先核对答案再提交结果，提示后不能选择独立做对。结果为用户自报，首版不自动批改。
12. 同题连续独立正确中，存在两次不同上海日历日且间隔至少24小时才标已验证。一次只记本次独立做对；后续仍错/提示重置连续正确证据。未完成、暂停、提前结束不按错计。
13. 创建计划和提交结果有幂等保护；仅一个活动/暂停计划。可暂停、恢复，刷新保留状态。删除题目清除关联分析和重做，计划中快照内容清空；删除资料连同原文件和该资料的所有题，其他资料保留。
14. 本地数据库持久化，启动将中断的任务标为可重试。识别按未成功页重试，不覆盖已成功页。模型接口异常显示认证/配置/额度/超时提示，原件及已成功结果保留。

## 4. 页面规格与实际原型

全部页面沿用左侧五个主入口，桌面右侧操作区，手机转换为紧凑导航；重要按钮明确说明下一步，不自动确认分析。

### 4.1 首次档案设置

关联：F001/F002。主要内容：昵称、年级、教材、学期名称和起止日期。

交互与规则：保存后进入首页；必填和日期先后校验，首版支持高一至高三数学。

![首次档案设置](../../public-prototypes/01-setup.jpg)

### 4.2 首页：空档案

关联：F001/F004/F020。主要内容：第一份资料入口、主动导入示例、模型配置提醒。

交互与规则：不自动填假历史；示例导入前不产生示例数据。

![首页：空档案](../../public-prototypes/02-home-empty.jpg)

### 4.3 首页：已有记录

关联：F014/F016/F017。主要内容：近期学习、错题数、接触考点数、待确认数、继续复习。

交互与规则：从近期记录到详情，从暂停计划继续；数值来自保存记录。

![首页：已有记录](../../public-prototypes/03-home.jpg)

### 4.4 资料录入

关联：F004—F007。主要内容：文件选择、图片顺序、移除、资料名称、实际学习日期。

交互与规则：提交生成预览后进入状态页；超范围、无文件、未来日期有明确提示。

![资料录入](../../public-prototypes/04-upload.jpg)

### 4.5 预览与识别状态

关联：F005/F006/F008。主要内容：逐页原图、处理状态、错误说明、开始识别、手动核对入口。

交互与规则：预览完成后可识别；失败可重试；已成功页保留。无Key时仍可核对与手动录入。

![预览与识别状态](../../public-prototypes/05-status.jpg)

### 4.6 题目核对

关联：F009/F012/F013。主要内容：左侧候选与选择，原页预览，题号/题干/作答/缺作答标记/作答状态。

交互与规则：逐题保存或手动加题；核对后分析选中题。实质修改新建版本，保存选题至档案。

![题目核对](../../public-prototypes/06-check.jpg)

### 4.7 逐题分析确认

关联：F010—F013。主要内容：实际题干与证据、模型原建议、答案、问题、考点、错因、动作、反思、疑问。

交互与规则：确认仅当前题；待确认独立保存。未保存编辑在保存档案时作为待确认保存，避免未经核对自动确认。

![逐题分析确认](../../public-prototypes/07-analysis.jpg)

### 4.8 学习历史

关联：F014/F019。主要内容：日期范围、考点、状态、关键词，学习记录与资料草稿。

交互与规则：筛选取交集，按学习日期倒序；打开错题或资料，待确认记录仍可回看。

![学习历史](../../public-prototypes/08-history.jpg)

### 4.9 错题详情

关联：F012/F014/F017/F019。主要内容：题干、作答、当前分析、版本、反思、历次重做。

交互与规则：回原资料核对，可靠错题可单题复习；删除单题先说明影响。

![错题详情](../../public-prototypes/09-question.jpg)

### 4.10 我的考点

关联：F011/F015。主要内容：章节分组、考点状态、关联题数、未记录说明。

交互与规则：点进考点轨迹。未记录显示未记录；不用虚假的掌握百分比。

![我的考点](../../public-prototypes/10-knowledge.jpg)

### 4.11 考点轨迹

关联：F015/F018。主要内容：相关原题、学习事件、重做时间、重复错因与检查动作。

交互与规则：可追溯至错题详情与考点复习，计数同题去重；不以总练习数代替掌握。

![考点轨迹](../../public-prototypes/11-point.jpg)

### 4.12 原题复习计划

关联：F016。主要内容：考点筛选、可选数量、候选及推荐理由、计划名称。

交互与规则：有未结束计划先继续或结束；无可靠题提示先确认分析；开始后固定本次快照。

![原题复习计划](../../public-prototypes/12-plan.jpg)

### 4.13 资料详情

关联：F007/F014/F019。主要内容：原页、原文件下载、名称日期、关联题目、示例标签、删除。

交互与规则：保存名称日期后历史同步更新；删除整份资料二次提示具体范围。

![资料详情](../../public-prototypes/13-source.jpg)

### 4.14 独立重做：答案隐藏

关联：F017。主要内容：当前题、进度、提示、核对答案、暂停与结束。

交互与规则：在纸上完成，答案未发到浏览器；提示永久计入本次，暂停保留。

![独立重做：答案隐藏](../../public-prototypes/14-practice-hidden.jpg)

### 4.15 独立重做：核对结果

关联：F017/F018。主要内容：参考答案、检查动作、三种自报结果。

交互与规则：查看提示后独立正确按钮禁用且服务端拒绝；提交仅记一次，自动下一题。

![独立重做：核对结果](../../public-prototypes/15-practice-answer.jpg)

### 4.16 设置与模型连接

关联：F002/F003。主要内容：孩子档案、API Key输入、官方接口、两个模型ID、连接验证、数据位置。

交互与规则：Key不回显，Windows加密本地保存；分别测试模型，调用可能计费。环境变量优先。

![设置与模型连接](../../public-prototypes/16-settings.jpg)

### 4.17 复习结果

关联：F018。主要内容：完成数、独立对/提示对/仍错、每题结果和继续入口。

交互与规则：完成写入原题与考点；未完成不按错，一次独立正确不宣称已掌握。

![复习结果](../../public-prototypes/17-result.jpg)

## 6. 空态、异常与验收口径

首次空档案提示录入；无模型Key提示设置或手动操作；无复习候选解释条件；无实际作答禁止个人错因确认；任务失败保留资料并提供重试；并发编辑提示版本冲突；删除后详情提示不存在。

核心验收指标为：真实题与作答被正确区分；分析有可定位证据；保存记录可追溯；重做进度刷新后保留；状态按规则更新。AI质量不能仅用接口成功率证明，真实样本验收见[ACCEPTANCE.md](ACCEPTANCE.md)。

## 7. 后续版本管理

每次版本开始冻结PRD、技术文档、功能ID和验收标准，开发完成更新实际截图与测试结果；变更在CHANGELOG说明理由及数据影响。P1/P2见功能清单，孩子实际使用反馈决定下一版，不在首版隐式添加。
