# v0.1.1 识别流程修正

学科通用读取页面文字，再区分习题、讲义、混合、无法读取。无习题是成功读取，不是失败。非数学可识别和核对，但明确不支持当前数学考点分析。保留文字、学科、页面类型；只有真正失败页重试，成功页不覆盖。已有资料和题目保留。页面原型和自测交付后补齐。

## 页面变更与原型

- 录入页：提前说明多学科可读取，当前仅数学考点分析。
- 状态页：新增每页文字、学科、页面类型。讲义页成功，不显示失败重试。
- 核对页：新增页面读取结果，原页下可展开文字；无候选题解释讲义无需重试。
- 英语等非数学题：分析接口阻止误用数学考点，允许核对和保存。
- 旧成功页：重新读取只补充学科与页面文字，不覆盖旧题、不重复生成候选。
